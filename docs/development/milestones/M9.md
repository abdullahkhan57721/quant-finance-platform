## Architecture constraints

The release preserves the established dependency direction:

```text
Qt Quick / QML
        ↓
curated PySide6 controller / item models
        ↓
frontend-neutral application + presentation
        ↓
public quantitative APIs + committed evidence
        ↓
production quantitative core
```

Release/presentation code is not a second implementation of quantitative semantics.

Protect these result boundaries:

```text
same-date held-out pricing evidence != temporal forecasting
calibration convergence != parameter identification
better held-out pricing != universal model validity
Heston pricing advantage != Heston hedge superiority
measured Python optimization != justification for a C++ backend
```
